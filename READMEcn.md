# 以撒桌宠

一个基于 C# / WPF 的 Windows 桌宠程序，角色来自《以撒的结合：忏悔》的主角，会在桌面上自由游走、睡觉、跟你互动。

## ✨ 功能

| 功能        | 说明                                                                      |
| --------- | ----------------------------------------------------------------------- |
| 🚶 自动游走   | 全向随机移动，撞屏幕边缘自动反弹，带惯性加速度 / 摩擦衰减                                          |
| 🎮 操控模式   | **左键点击**进入：`WASD` 控身体移动（向量叠加、斜向归一化），`方向键` 独立控制头部朝向（带眨眼循环），`Esc` 或窗口失焦退出 |
| 💤 睡觉循环   | 清醒 100-140s → 发呆 45-75s → 睡觉 4-6min，自动切换                                |
| 👋 光标互动   | 光标静止 45s 后，桌宠自动走到光标下方，摆出**双手上举**姿势"举"起光标，鼠标一动立刻恢复游走                     |
| ✨ 受伤动画    | 随机频率触发闪烁动画                                                              |
| 👍 竖大拇指   | 随机触发或与光标互动时展示                                                           |                        |
| 🖱️ 拖拽移动  | 按住左键拖拽可以手动移动桌宠（有 5 像素阈值区分点击 / 拖动）                                       |

## 🚀 快速开始

### 直接运行（推荐）

下载 `issac.exe` 双击即可，无需安装 .NET，无需任何外部资源。

## 🎮 操作说明

| 操作              | 效果             |
| --------------- | -------------- |
| 左键点击（短按）        | 进入操控模式         |
| 左键拖拽            | 手动移动桌宠         |
| `W` `A` `S` `D` | 操控模式下移动（可组合斜向） |
| `↑` `↓` `←` `→` | 操控模式下独立控制头部方向  |
| `Esc`           | 退出操控模式         |

## 🏗️ 技术栈

- **语言**：C# 12

- **框架**：.NET 10 / WPF（透明分层窗口 `AllowsTransparency` + `WindowStyle=None`）

- **编译**：`Microsoft.NET.Sdk` / 系统 `csc.exe`

- **窗口定位**：`SetWindowPos` + DPI 物理像素吸附，解决 150% 缩放下的亚像素拖影

- **键盘输入**：`WH_KEYBOARD_LL` 全局低级钩子（操控期间吞掉按键，不影响其他窗口）

- **鼠标输入**：手动拖拽状态机（`MouseDown/Move/Up`，5px 阈值区分点击与拖动）

- **移动**：双速度惯性模型（实际速度 → 目标速度指数逼近）

## ⚠️ 已知限制

- **仅支持 Windows**（使用了 Win32 API：`SetWindowPos`、`SetWindowsHookEx`、`GetCursorPos`）

- **分辨率适配**：目前仅在 150% DPI 缩放下测试过

- **全屏游戏**：桌宠窗口置顶透明，但全屏游戏会截获键鼠事件，此时操控和点击都无效
